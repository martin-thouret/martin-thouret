## 🚀 Projets clés

### 🎙️ Onsho – Sous-titres live multilingues
Plateforme de sous-titrage en temps réel intégrée à WordPress, avec :
- Synchronisation Vmix
- Traduction automatique avec Google Translate
- Interface React avec réglages dynamiques
- Backend Flask + MongoDB

### 🥾 Randopif – Application de randonnées
Générateur d’itinéraires de randonnée personnalisés, avec :
- Cartographie, météo, niveau de sécurité
- Application mobile Flutter
- Backend sécurisé en FastAPI + MongoDB
- Authentification, gestion de profils, filtres, presets

### 💼 FreelanceHub – Outil pour freelances
SaaS pour générer contrats et factures en ligne avec :
- Page "Account" pour pré-remplissage
- Stockage MongoDB
- Génération PDF
- Dashboard et gestion de ressources (documents, dossiers)

### 🎥 PTZ Controller – Pilotage caméra IP
Interface React pour piloter des caméras PTZ :
- Commandes VISCA over UDP
- Mouvements auto (ping-pong)
- Réglage de vitesse, presets dynamiques
- Application packagée en `.exe` autonome (Node.js + Electron-like)
